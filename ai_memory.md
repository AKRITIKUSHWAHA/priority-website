## 3. Tech Stack Architecture
- **Framework:** Next.js 14+ (App Router)
- **Language:** TypeScript / JavaScript (React 18+)
- **Styling:** Modern Vanilla CSS / CSS Modules with Design Tokens (Variables for theme colors, glassmorphism, glowing accents, responsive breakpoints).
- **Icons:** Lucide React / FontAwesome modern icons.
- **Animations:** CSS Keyframes, Smooth Transitions, Parallax Cards, and Interactive Hover States.
- **Components & Features:**
  1. **Global Header & Navigation:** Translucent glassmorphism navbar with quick tracking bar & emergency contact drawer.
  2. **Hero Section:** High-impact animated headline, dynamic metric counters, and an **Interactive Live Track & Trace** system.
  3. **Instant Freight Quote Estimator:** Real-time distance, cargo type, tonnage, and route pricing calculation widget.
  4. **Interactive Corridor / SADC Route Map:** Visual cross-border network (Beira, Durban, Harare, Lusaka, Lubumbashi, Walvis Bay corridors).
  5. **Core Services Matrix:**
     - Cross-Border Haulage & Full Truckload (FTL)
     - Abnormal Loads & Mining Equipment Transportation
     - Cold Chain & Temperature-Controlled Freight
     - Dangerous Goods (ADR / Hazchem)
     - Warehousing, Bonded Storage & Customs Clearing
  6. **Fleet & Telematics Showcase:** Satellite GPS tracking, driver fatigue monitoring, fuel efficiency, modern eco-compliant truck fleet.
  7. **Client Portal & Consignment Tracking Simulation:** Realistic live milestone progress (Customs, In-Transit, Border Clearance, Delivered).
  8. **Testimonials & Corporate Credibility:** ISO certifications, mining/agricultural partner logos, and safety compliance awards.
  9. **Interactive Contact & Dispatch Center:** Instant WhatsApp dispatch link, direct inquiry form, 24/7 hotline.

## 4. Key Decisions & Preferences
- **Tone:** Professional, powerful, reliable, ultra-modern, and technologically advanced.
- **10x Experience over Previous Site:** Replace static old Bootstrap template with responsive, dynamic, interactive web app featuring instant quoting, interactive route discovery, dynamic tracking simulator, and fluid micro-interactions.
- **Performance:** Sub-second page loads, SEO-optimized metadata, OpenGraph tags, semantic HTML5, zero lag.
